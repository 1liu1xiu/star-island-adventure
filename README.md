# 星岛答题大冒险

一款适合小学一、二年级的触摸答题沙箱游戏。孩子可以在连续的方块地图中自由走动、挖矿、打怪兽，通过数学、语文和英语题目完成 30 关冒险。

## 游戏内容

- 5 个主题世界、30 张开放地图和最终 BOSS
- 四方向自由移动、镜头跟随和小地图
- 数学、语文、英语随机题目，每题限时作答
- 超时或答错扣血，支持药水、复活宝石和重新挑战
- 通关奖励及“iPad 畅玩 1 小时券”家长兑换流程
- 自动保存本机进度，支持 iPad 横竖屏触控
- 正式版首次联网打开后可离线继续游玩

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

## 构建与检查

```bash
npm run lint
npm run build
node scripts/validate-content.mjs
```

项目使用 React、TypeScript 和 Vite。游戏进度仅保存在玩家当前浏览器的本地存储中，不会上传到服务器。
